# AI Compare (SUSE): AI Compare app

The AI Compare app (SUSE BCI images): asks the same prompt of Ollama directly and through Open WebUI + Pipelines, and compares the answers.

Part of the **ai-compare-suse** SUSE AI Factory blueprint (Ollama, Open WebUI and Pipelines plus the AI Compare components). Install all components into the same namespace (the blueprint does this for you).
