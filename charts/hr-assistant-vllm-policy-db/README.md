# hr-assistant-vllm-policy-db

HR Policy Database app and the demo dashboard (at /). Uses Qdrant and OpenSearch for retrieval and the vLLM router for answers.

This chart is one component of the `hr-assistant-vllm` SUSE AI Factory blueprint (`catalog/blueprints/hr-assistant-vllm-1-4-1.yaml`). It vendors `charts/hr-assistant-vllm` (alias `hr`) and enables only this workload. See `charts/hr-assistant-vllm/README.md` for the full component list, how the components connect, and how to install the blueprint.
