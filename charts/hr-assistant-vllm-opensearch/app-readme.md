# HR Assistant (vLLM): OpenSearch search engine

OpenSearch (SUSE Application Collection) search engine. hr-policy-db indexes and queries HR policies in it; SUSE Observability shows it under Search Engines.

Part of the **hr-assistant-vllm** SUSE AI Factory blueprint, which deploys each of its eight pods as a separate component. Install all eight into the same namespace (the blueprint does this for you).
