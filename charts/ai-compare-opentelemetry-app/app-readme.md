# AI Compare (OpenTelemetry): AI Compare app

The AI Compare app: asks the same prompt of Ollama directly and through Open WebUI + Pipelines, and compares the answers. GenAI telemetry, token and cost tracking go to SUSE Observability.

Part of the **ai-compare-opentelemetry** SUSE AI Factory blueprint (Ollama, Open WebUI and Pipelines plus the AI Compare components). Install all components into the same namespace (the blueprint does this for you).
