# hr-assistant-vllm-app

The HR Assistant conversational app. Calls the vLLM router and fans out to employee-handbook and hr-policy-db.

This chart is one component of the `hr-assistant-vllm` SUSE AI Factory blueprint (`catalog/blueprints/hr-assistant-vllm-1-4-3.yaml`). It vendors `charts/hr-assistant-vllm` (alias `hr`) and enables only this workload. See `charts/hr-assistant-vllm/README.md` for the full component list, how the components connect, and how to install the blueprint.
