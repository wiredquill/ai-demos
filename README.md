# aif/upstream-charts

Community Helm charts republished with SUSE AI Factory install forms, for the
`wiredquill-upstream` Rancher ClusterRepo. They pair with the SUSE Application
Collection charts on `aif/hr-assistant-vllm` so the SUSE and upstream AI Compare
blueprints compare like for like. Built by `scripts/package-aif-charts.sh <dir>
upstream` on the main branch; forms and patches live in `catalog/charts/`.
