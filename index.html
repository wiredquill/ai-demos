AI Demos Helm Chart Repository

This is a Helm chart repository hosted on GitHub Pages. Charts are available for installation in Kubernetes environments.

Available Charts

ai-compare-opentelemetry

Latest Version: 0.1.314

Description: Advanced observability-focused AI response comparison platform with comprehensive GenAI telemetry, token-level cost tracking, and SUSE Observability integration.

Install: helm install my-release https://wiredquill.github.io/ai-demos/ --repo https://wiredquill.github.io/ai-demos/ --version 0.1.314

ai-compare

Latest Version: 0.1.306

Description: Side-by-side AI response comparison platform featuring Ollama, Open WebUI, and custom chat interface with security demonstrations.

Install: helm install my-release https://wiredquill.github.io/ai-demos/ --repo https://wiredquill.github.io/ai-demos/ --version 0.1.306

ai-compare-suse

Latest Version: 0.1.306

Description: Enterprise AI response comparison platform optimized for SUSE environments with BCI images and NeuVector security demos.

Install: helm install my-release https://wiredquill.github.io/ai-demos/ --repo https://wiredquill.github.io/ai-demos/ --version 0.1.306

Add Repository

Add this repository to your Helm client:

helm repo add ai-demos https://wiredquill.github.io/ai-demos/

helm repo update
