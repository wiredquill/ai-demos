      Demo scenarios

      Availability
      Turning it on swaps the models-latest key in the demo ConfigMap for models_latest. The app notices and its /health and chat endpoints stop responding, so SUSE Observability shows the outage and links it to the ConfigMap change. Turn it off here or patch the ConfigMap back with kubectl.
      Data leak
      Posts well-known synthetic test patterns (not real data) to httpbin.org. With a NeuVector DLP rule in place, the outbound packets raise a security event for this workload.
      Pipeline levels
      Path B goes through the Open WebUI Pipelines service, which rewrites the prompt for one of five audience levels. The level rotates every 30 seconds so back-to-back questions show different styles.
      Load simulator
      Creates a small deployment that calls this app's API on a timer. Needs RBAC to create deployments in this namespace; use the bundled load-gen component if that isn't granted.
