# ai-compare-suse-app

The AI Compare app (SUSE BCI images): asks the same prompt of Ollama directly and through Open WebUI + Pipelines, and compares the answers.

This chart is one component of the `ai-compare-suse` SUSE AI Factory blueprint (`catalog/blueprints/ai-compare-suse-1-0-0.yaml`). It vendors `charts/ai-compare-suse` (alias `aic`) and enables only this workload. See the repository README ("SUSE AI Factory Blueprints") for the component list and how to install the blueprint.
